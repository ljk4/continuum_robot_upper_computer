# 绳驱动并联机器人上位机控制系统

机器人结构设计课程大作业。通过摄像头检测 AprilTag 标记获取末端位置，经逆运动学计算绳位移，通过 UART 将目标值发送给 STM32 下位机，实现闭环控制。

## 目录结构

```
├── config.py            -- 集中配置参数（dataclass）
├── main.py              -- 主程序入口，50Hz 控制循环
├── ik_solver.py         -- 逆运动学（PCC 两节连续体机器人，阻尼最小二乘求解）
├── vision_tracker.py    -- 视觉位姿检测（AprilTag 36h11，solvePnP 解算）
├── protocol.py          -- 串口通信协议（帧打包/解包/CRC16-Modbus）
├── serial_manager.py    -- 串口管理（线程安全封装）
├── sender.py            -- 100Hz 发送线程
├── receiver.py          -- 接收线程（解析编码器反馈和 ACK）
└── fake_stm32.py        -- STM32 下位机模拟器（无需硬件即可测试）
```

## 快速开始

### 仿真模式（无需硬件）

需要虚拟串口对（如 com0com），将 COM13 和 COM14 连接。

```bash
# 终端 1：启动模拟下位机
python fake_stm32.py

# 终端 2：启动上位机
python main.py
```

### 真实硬件

1. 连接摄像头和 STM32
2. 修改 `config.py` 中的串口端口和相机参数
3. 运行 `python main.py`

## 通信协议

39 字节定长帧：

| 字段 | 长度 | 说明 |
|------|------|------|
| 帧头 | 2B | 0xAA 0x55 |
| 命令字 | 1B | 0x01=目标 / 0x02=停止 / 0x03=查询 |
| 数据 | 32B | 8 x float32（绳长或编码器值） |
| CRC16 | 2B | Modbus 校验 |
| 帧尾 | 2B | 0x0D 0x0A |

## 运动学模型

### PCC 假设（分段常曲率）

采用 PCC（Piecewise Constant Curvature）模型，将连续体机器人每一段近似为等曲率圆弧。每段用两个配置变量描述：

- **theta** (θ) — **单节**弯曲角 (rad)，段的弯曲幅度。总弯曲角 = 段数 × θ
- **phi** (φ) — 弯曲平面角 (rad)，弯曲方向

两节机器人共有 4 个配置变量：`q = [theta1, phi1, theta2, phi2]`，均为**单节**弯曲角。

> **注意**：`theta` 是单节弯曲角，不是总弯曲角。例如 6 段串联、总弯曲角 40° 时，`theta1 = 40°/6 ≈ 6.67°`。

### 单节运动学

#### 变换矩阵

当 θ ≠ 0 时，曲率半径 ρ = L/θ，单节从基座到末端的齐次变换矩阵为：

```
T = [ R(φ,θ)   p(φ,θ) ]
    [  0  0  0    1    ]
```

其中位置向量：
```
px = ρ * (1 - cos θ) * cos φ
py = ρ * (1 - cos θ) * sin φ
pz = ρ * sin θ
```

旋转矩阵：
```
R = Rz(φ) * Ry(θ) * Rz(-φ)
```

当 θ = 0（直立）时，简化为 `T = [I, [0,0,L]]`。

#### 腱/绳映射

4 根绳均匀分布在半径为 r 的圆周上，绳位移 dl 与配置变量的关系：

```
绳1: dl = -r * θ * cos(φ)
绳2: dl = +r * θ * sin(φ)
绳3: dl = +r * θ * cos(φ)
绳4: dl = -r * θ * sin(φ)
```

绳分布俯视图（从上往下看）：

```
       绳2 (Y+)
        |
绳1 ----+---- 绳3 (X+)
(X-)    |
       绳4 (Y-)
```

- X 轴：绳1 → 绳3 方向（正方向指向绳3）
- Y 轴：绳4 → 绳2 方向（正方向指向绳2）
- Z 轴：竖直向上（右手定则）

绳1 和绳3 控制 X 方向弯曲，绳2 和绳4 控制 Y 方向弯曲。

### 多段机器人结构

机器人由两部分组成，每部分包含多个相同 PCC 段串联，总计 8 根绳：

```
基座 ─── 第一部分(n段) ─── 第二部分(m段) ─── 末端
  │         │                  │
  ├── 绳1 ──┤ 锚定             │
  ├── 绳2 ──┤ 锚定             │
  ├── 绳3 ──┤ 锚定             │
  ├── 绳4 ──┤ 锚定             │
  ├── 绳5 ────────────────────┤ 锚定（穿过第一部分）
  ├── 绳6 ────────────────────┤ 锚定
  ├── 绳7 ────────────────────┤ 锚定
  └── 绳8 ────────────────────┘ 锚定
```

- 第一部分：n 个相同段串联，4 根绳（绳1-4）锚定在第一部分末端
- 第二部分：m 个相同段串联，4 根绳（绳5-8）穿过第一部分锚定在第二部分末端
- 同组内所有段弯曲角 θ 和弯曲平面角 φ 完全一致（同一组绳驱动同步弯曲）
- 配置空间仍为 4 维：`q = [θ1, φ1, θ2, φ2]`

#### 正运动学

n 段级联和 m 段级联：

```
T_total = T(θ1, φ1)^n @ T(θ2, φ2)^m
```

末端位置 = `T_total[:3, 3]`（4 维配置 → 3 维位置，存在 1 个冗余自由度）

#### 腱位移累加（含耦合补偿）

绳5-8 穿过第一部分，当第一部分弯曲时，这些绳的路径长度也会变化。完整的绳位移计算：

```
绳 1-4 总位移 = n × dl(θ1, φ1)                          （仅第一节弯曲）
绳 5-8 总位移 = m × dl(θ2, φ2) + n × dl(θ1, φ1)        （第二节自身 + 穿过第一节的路径变化）
```

耦合项 `n × dl(θ1, φ1)` 的物理含义：
- 第一部分弯曲时，绳在弯曲外侧伸长、内侧缩短
- 绳5-8 与绳1-4 在截面上方位角相同，穿过同一弯曲路径
- 路径长度变化与对应的第一部分绳位移同号

> **待确认**：上述耦合计算假设绳5 与绳1 同方位角、绳6 与绳2 同方位角……即绳5-8 分别穿过绳1-4 的通道。如果实物绳布局不同，需调整耦合项的对应关系。

#### 逆运动学

由于 4 配置变量映射到 3 维位置，系统欠约束。采用**阻尼最小二乘法**（Levenberg-Marquardt 风格）求解：

```
dq = J^T * (J * J^T + λ * I)^(-1) * error
```

其中：
- `J` — 3×4 数值雅可比矩阵（有限差分法计算，步长 h=1e-6 rad）
- `error = target_pos - current_pos` — 3 维位置误差
- `λ` — 阻尼系数（默认 1e-3），防止奇异点发散
- 步长策略：全步长优先，误差增大时回溯减半（最多 5 次），优于固定步长

收敛条件：`||error|| < 1e-4 m`（0.1mm 精度）或达到最大迭代次数 50。

### 完整求解链路

```
目标位置 [x, y, z]（机器人坐标系）
    │
    ▼
IK 求解 → 配置 q = [θ1, φ1, θ2, φ2]（单节弯曲角）
    │
    ▼
腱映射（含耦合补偿） → 8 根绳位移 dl (m)
    │
    ▼
圈数转换 → rotations = dl / (π * D)
    │
    ▼
下发给下位机（从零位算起的绝对圈数）
```

其中 D 为绳盘直径（默认 10mm）。

### 视觉坐标变换

相机检测到的 AprilTag 位姿在相机坐标系下，需变换到机器人坐标系后才能输入 IK 求解器：

```
pose_robot = cam_to_robot_R @ pose_cam + cam_to_robot_t
```

当前 `cam_to_robot_R = I`、`cam_to_robot_t = [0,0,0]`（单位变换，待标定后替换）。
